# QA

Проверять после изменений, затрагивающих игру, сохранение, UI или SDK.

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| QA-01 | Новый запуск | Игра загружается, стартовая кнопка доступна |
| QA-02 | Обучение | Новый игрок проходит обучение; существующий его не получает повторно |
| QA-03 | Ремонт | Клик увеличивает деньги и детали |
| QA-04 | Комбо | Серия ремонтов корректно изменяет множитель |
| QA-05 | Инструмент | Покупка списывает деньги и повышает уровень |
| QA-06 | Автоматизация | Покупка повышает уровень и пассивный доход |
| QA-07 | Задания | Выполненное задание можно получить один раз |
| QA-08 | Достижения | Выполненное достижение сохраняется |
| QA-09 | Поставка | Поставка доступна не более одного раза в день |
| QA-10 | Заказ | Заказ списывает детали и выдаёт награду |
| QA-11 | Автомобиль | Дополнительный автомобиль собирается и сохраняется |
| QA-12 | Гараж | Доступный гараж выбирается и сохраняется |
| QA-13 | Turbo | Rewarded-видео выдаёт предусмотренный бонус |
| QA-14 | Offline | После перерыва начисляется offline-доход |
| QA-15 | Реклама | Во время рекламы игра и звук приостанавливаются |
| QA-16 | Видимость | При скрытии страницы активный игровой цикл останавливается |
| QA-17 | Перезагрузка | Сохранение восстанавливается после reload |
| QA-18 | Поворот | Смена ориентации не сбрасывает состояние |
| QA-19 | Сброс | Подтверждённый сброс очищает прогресс |
| QA-20 | Mobile | Основные действия доступны одной рукой, без горизонтального overflow |
| QA-21 | Long-tap | Нет системного выделения и контекстного меню внутри игры |
| QA-22 | Desktop | Интерфейс корректно отображается на широком экране |
| QA-23 | Console | Нет page errors и console errors |
| QA-24 | Game Ready | Ready вызывается после загрузки и до первого взаимодействия |
| QA-25 | Gameplay API | Start/stop соответствуют состоянию игры |
| QA-26 | I18N | Язык определяется через SDK environment |

## Автоматические проверки

CI выполняет:

- `node --check game.js`;
- `node tests/game.test.js`;
- Playwright smoke-тест на мобильном viewport;
- проверку релизного ZIP и его структуры.
