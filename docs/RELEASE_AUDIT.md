# Предрелизный аудит — «Гаражный Магнат»

Дата подготовки: 2026-10-04  
Ветка: `main`

## Цель

Этот документ — финальный чек-лист перед загрузкой игры в Консоль разработчика Яндекс Игр. Новые игровые механики перед релизом не добавляются без отдельной причины: на этом этапе важнее стабильность.

## Автоматически проверяется

- JavaScript проходит `node --check game.js`.
- 30 инструментов.
- 40 уровней автоматизации.
- 30 достижений.
- Новый игрок начинает с 0 ₽.
- Стартовый автомобиль принадлежит игроку сразу.
- В автопарке доступны для покупки только 4 дополнительных автомобиля.
- Первый клик приносит деньги и детали.
- Покупка инструмента работает.
- Покупка автоматизации работает.
- Пассивный доход работает.
- Сохранение записывается в `localStorage`.
- Повреждённое сохранение нормализуется.
- Сброс очищает прогресс.
- Сортировка задач ставит выполненные/ближайшие задачи в ожидаемом порядке.
- Playwright smoke-тест проверяет запуск на мобильном viewport, клик, покупку и восстановление после перезагрузки.

## Обязательно проверить вручную в Консоли Яндекс Игр

### SDK

- [ ] Debug-панель показывает актуальный loader.
- [ ] Game Ready становится зелёным только когда игра действительно готова.
- [ ] Gameplay API становится активным во время игры.
- [ ] Gameplay API останавливается при открытии модалок.
- [ ] Gameplay API останавливается перед рекламой.
- [ ] Gameplay API возобновляется после рекламы.
- [ ] При потере фокуса игра останавливается.
- [ ] После возврата фокуса игра продолжает работу только если модальное окно закрыто.
- [ ] В debug-панели индикатор I18N показывает, что автоопределение языка используется.

### Сохранение

- [ ] Купить инструмент → обновить страницу → уровень сохранён.
- [ ] Купить автоматизацию → обновить страницу → уровень сохранён.
- [ ] Собрать автомобиль → обновить страницу → автомобиль сохранён.
- [ ] Сменить гараж → обновить страницу → выбранное состояние корректно.
- [ ] Получить достижение → обновить страницу → достижение сохранено.
- [ ] Забрать задачу → обновить страницу → задача остаётся выполненной.
- [ ] Получить поставку → обновить страницу → повторная поставка в тот же день недоступна.
- [ ] Закрыть/свернуть игру → открыть снова → прогресс сохранён.
- [ ] Повернуть мобильное устройство → состояние не теряется.
- [ ] Полный сброс требует точного подтверждения и очищает прогресс.

### Реклама

- [ ] Turbo запускается только по явному нажатию пользователя.
- [ ] На кнопке ясно указано, что будет показано видео и что пользователь получит ×3.
- [ ] После полного rewarded video выдаётся только предусмотренная награда.
- [ ] Если реклама закрыта без награды, бонус не выдаётся.
- [ ] Offline ×2 выдаётся только после rewarded callback.
- [ ] Fullscreen появляется только в логической паузе после prestige.
- [ ] Во время рекламы игровой процесс и звук не продолжаются.
- [ ] После рекламы прогресс не сбрасывается.

### Мобильный UX

- [ ] Игра корректно работает в заявленной ориентации.
- [ ] Основной экран помещается без горизонтальной прокрутки.
- [ ] Все основные кнопки удобно нажимаются одной рукой.
- [ ] Long-tap не вызывает системное выделение/контекстное меню внутри игры.
- [ ] Нет наложения текста и кнопок.
- [ ] Нет системного видеоплеера.
- [ ] Нет WebGL-заглушки.
- [ ] Нет ошибок в DevTools console.

### Геймплей

- [ ] Первый запуск проходит через обучение.
- [ ] Повторный запуск не показывает обучение существующему игроку.
- [ ] Клик приносит деньги и детали.
- [ ] Комбо работает до ×10.
- [ ] OVERDRIVE работает.
- [ ] Инструменты открываются по обороту.
- [ ] Автоматизация открывается по обороту.
- [ ] Задания можно забрать сразу после выполнения.
- [ ] Выполненное задание визуально отмечается.
- [ ] Поставка выдаётся максимум один раз в локальный календарный день.
- [ ] Заказы расходуют детали и дают награду.
- [ ] Дополнительные автомобили собираются за детали.
- [ ] Стартовая «Старая Ласточка» не появляется как покупаемая машина.
- [ ] Гаражи открываются по обороту.
- [ ] Prestige требует правильный оборот и даёт постоянный бонус.
- [ ] После prestige текущая ветка сбрасывается, а мета-прогресс сохраняется.

## Что сознательно не используется

- Инап-покупки.
- Внешние рекламные сети.
- Внешние платежи.
- Авторизация, необходимая для запуска игры.
- Внешние ссылки из интерфейса.
- Облачные сохранения Яндекс Игр.
- YouTube или сторонний видеоплеер.

## Релизный статус

Технические изменения считаются завершёнными после успешного CI на последнем commit и ручной проверки черновика через debug-панель Яндекс Игр.

Важно: успешные локальные тесты не заменяют проверку черновика на стороне Яндекса.
