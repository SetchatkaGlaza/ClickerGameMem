# Архитектура кода

## Файлы

- `index.html` — разметка игрового интерфейса, loading screen, нижняя навигация и контейнер модалок.
- `style.css` — адаптивный мобильный-first интерфейс, состояния кнопок, карточки, модальные окна и защита от long-tap выделения.
- `game.js` — вся игровая логика: состояние, экономика, прогрессия, сохранение, UI, реклама и SDK.
- `tests/game.test.js` — unit/integration-проверки ядра через Node VM.
- `tests/browser.smoke.cjs` — запуск Chromium с мобильным viewport и базовый smoke-сценарий.
- `assets/ASSET_GUIDE.md` — список игровых изображений и требования к арт-направлению.
- `docs/RELEASE_AUDIT.md` — финальный чек-лист перед модерацией.
- `docs/QA_MATRIX.md` — пошаговые ручные QA-сценарии.
- `docs/YANDEX_SUBMISSION.md` — подготовленные тексты и поля для черновика Яндекс Игр.

## Слои game.js

### 1. Данные каталога

`GARAGES`, `TOOL_NAMES`, `AUTO_NAMES`, `CARS`, `ACHIEVEMENTS`, `TASKS`.

Это статические данные игры. Изменение их количества должно сопровождаться обновлением тестов.

### 2. Состояние

`defaultState()` создаёт чистую игру.

`normalizeState()` приводит localStorage к безопасной форме и отбрасывает повреждённые значения. Стартовый автомобиль всегда восстанавливается как принадлежащий игроку.

### 3. Экономика

- `toolBonuses()` собирает бонусы инструментов.
- `carBonus()` рассчитывает бонус автопарка.
- `multiplier()` объединяет бонусы автомобиля, гаража, репутации, prestige и Turbo.
- `income()` рассчитывает пассивный доход.
- `clickValue()` рассчитывает активный доход за ремонт.

### 4. Прогресс

Клик увеличивает `totalClicks`, `runEarned` и `lifetimeEarned`.

Покупки, задания, заказы, автомобили, гаражи и prestige используют эти значения как основу разблокировок.

### 5. Сохранение

Основной ключ:

`garage_tycoon_idle_v3`

Поддерживаются legacy-ключи:

- `garage_tycoon_v1`
- `garage_tycoon_v2`

Сохранение выполняется:
- сразу после важных действий;
- примерно каждые 5 секунд;
- при `beforeunload`;
- при потере видимости страницы.

### 6. Yandex Games SDK

SDK загружается через `/sdk.js`.

Используются:
- `YaGames.init()`;
- `LoadingAPI.ready()`;
- `GameplayAPI.start()/stop()`;
- события `game_api_pause/game_api_resume`;
- `showRewardedVideo()`;
- `showFullscreenAdv()`;
- `environment.i18n.lang`.

При недоступном SDK базовый геймплей не блокируется.

### 7. UI

`render()` обновляет основное состояние экрана только когда установлен dirty-флаг.

Большие каталоги открываются модальными окнами. После покупки или получения награды соответствующая модалка перерисовывается, поэтому устаревшие уровни и кнопки не остаются на экране.

### 8. Prestige

Prestige сбрасывает текущий цикл:
- деньги;
- детали;
- инструменты;
- автоматизации;
- текущий оборот;
- текущий гараж.

Сохраняет мета-прогресс:
- филиалы;
- автомобили;
- достижения;
- lifetime-статистику;
- репутацию;
- задания/дневные данные;
- профиль;
- звук.

## Правило релизных изменений

Перед изменением игровой механики:

1. Обновить логику.
2. Добавить/обновить тест.
3. Проверить `node --check game.js`.
4. Дождаться CI.
5. Повторить ручной сценарий из `docs/QA_MATRIX.md`, если изменение затрагивает UI или SDK.
6. Не менять баланс и прогрессию непосредственно перед модерацией без необходимости.
