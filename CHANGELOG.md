# История изменений

## 1.0.0 — подготовка релиза

- стабилизирована модель состояния автопарка;
- усилена нормализация локальных сохранений;
- исправлено восстановление состояния после перезагрузки;
- навигация переведена на внутреннюю прокрутку игрового контейнера;
- профиль получил встроенную форму редактирования имени;
- улучшено управление Gameplay API при модальных окнах, смене видимости и рекламе;
- добавлена проверка языка через SDK;
- расширены автоматические проверки игрового ядра и браузерного запуска;
- добавлена автоматическая сборка и проверка релизного ZIP;
- упрощена техническая документация.
