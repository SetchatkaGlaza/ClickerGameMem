# Changelog

## Предрелиз — 2026-10-04

### Stability
- Уточнена модель состояния автопарка: всегда 5 слотов, включая стартовую машину.
- Стартовая «Старая Ласточка» не является покупаемым автомобилем.
- Усилена нормализация сохранений.
- После prestige выбранный гараж сбрасывается на доступный стартовый гараж.
- Исправлено возобновление Gameplay API поверх открытой модалки.
- Закрытие модалки не запускает gameplay, если документ скрыт.
- Добавлена защита от системного context menu и выделения текста long-tap внутри игры.
- Turbo теперь уважает cooldown.
- Добавлено автоопределение языка через SDK с русским fallback.

### QA
- Расширены unit-тесты критических инвариантов автопарка и задач.
- Playwright smoke-тест проверяет мобильный запуск, первый клик, покупку и восстановление сохранения.

### Documentation
- Добавлены предрелизный аудит, матрица QA и инструкция заполнения черновика Яндекс Игр.
