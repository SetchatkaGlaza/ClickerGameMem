# 67: Brainrot Factory — v0.2

HTML5 incremental/clicker MVP под Яндекс Игры.

## Стек
HTML5 + CSS3 + Vanilla JavaScript + Yandex Games SDK.

## Реализовано в v0.2
- клики и пассивный доход;
- комбо до x10;
- критические клики;
- 4 типа улучшений;
- фабрика с глобальным бонусом;
- эволюция и коллекция;
- достижения;
- престиж;
- локальное сохранение;
- rewarded-video заготовка;
- адаптивный мобильный UI;
- простой звуковой feedback.

## Локальный запуск
```bash
python -m http.server 8080
```
Открыть:
http://localhost:8080
