# 67: Brainrot Vault — v0.5

Красочный HTML5 idle/clicker для Яндекс Игр. Игровая петля построена вокруг мем-сейфа: активный жмак и производство заполняют его, а игрок вручную забирает партии в кошелёк и вкладывает их в следующий уровень фабрики.

## Игровые системы

- **Мем-сейф:** ограниченная вместимость добавляет решение «когда забирать» и не даёт пассивному доходу превратить игру в фон без взаимодействия.
- **Пять производственных цехов:** от 67-ларька до гига-сервера, каждый имеет собственную стоимость, рост цены и производительность.
- **Активная прокачка:** сила жмака, вместимость сейфа и шанс гига-импульса.
- **Долгий прогресс:** шесть фабричных эпох от 0 до 250B созданной энергии; первый престиж доступен только на 500M.
- **Причины вернуться:** сменная награда, ежедневный контракт, 30-секундная вылазка с наградой, офлайн-производство до 4 часов и ловля редкого золотого мема.
- **Мета-прогресс:** лаборатория, архив из шести артефактов, достижения и постоянный бонус от престижа.
- **Платформа:** подготовлены `LoadingAPI`, `GameplayAPI`, пауза на скрытой вкладке и добровольное rewarded-video вознаграждение для Яндекс Игр.

## Оригинальные ассеты

- `assets/backgrounds/vault-city.svg` — ночной фон города-фабрики;
- `assets/ui/meme-vault.svg` — интерактивный мем-сейф;
- `assets/ui/meme-core.svg` — кнопка-мемомёт;
- `assets/ui/golden-meme.svg` — редкий золотой мем.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте <http://localhost:8080>. Для чистого прогона воспользуйтесь кнопкой «Сбросить».

## Релизная проверка

1. Проверить rewarded video, player data и поведение `GameplayAPI` в черновике Яндекс Игр.
2. Пройти первую сессию на телефоне и desktop: жмак → сейф → сбор → каждый цех → контракт → вылазка → престиж.
3. Подготовить отдельные иконку, скриншоты, возрастной рейтинг и описание.
4. Упаковать файлы так, чтобы `index.html` находился в корне ZIP-архива.
