# Гаражный Магнат

Браузерный idle/clicker о развитии автосервиса: от небольшого гаража до сети автоматизированных мастерских.

## Запуск

Игра не требует сборки и запускается как статический сайт.

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## Игровые системы

- активный ремонт с комбо, критическими наградами и OVERDRIVE;
- 30 инструментов с уровнями и бонусами;
- 40 уровней автоматизации и пассивный доход;
- 5 гаражей и 5 автомобилей;
- репутация и prestige-прогрессия;
- задания и 30 достижений;
- заказы и ежедневная поставка деталей;
- offline-доход;
- профиль механика;
- локальное сохранение;
- интеграция с Yandex Games SDK и рекламными форматами SDK.

## Сохранение

Текущее сохранение хранится в `localStorage` под ключом `garage_tycoon_idle_v3`.

Поддерживаются старые ключи `garage_tycoon_v1` и `garage_tycoon_v2`. Сохранение записывается после важных действий, периодически во время игры и при скрытии страницы.

## Проверка

Быстрая проверка:

```bash
node --check game.js
node tests/game.test.js
```

Браузерный smoke-тест требует Playwright:

```bash
npm install --no-save playwright@1.55.0
npx playwright install chromium
python3 -m http.server 4173
node tests/browser.smoke.cjs
```

Полный CI повторяет эти проверки и дополнительно собирает релизный ZIP.

## Структура

```text
index.html                 интерфейс игры
style.css                  стили и адаптивная вёрстка
game.js                    состояние, игровая логика, UI и SDK
assets/                    игровые изображения
tests/game.test.js         проверки игрового ядра
tests/browser.smoke.cjs    браузерный smoke-тест
scripts/package-release.sh сборка релизного архива
docs/                      техническая документация и QA
```

## Релизная сборка

```bash
bash scripts/package-release.sh
```

Скрипт создаёт `dist/GarageTycoon-v1.0.0.zip`, проверяет структуру архива и его размер.

В релизный архив входят только файлы, необходимые для запуска игры: `index.html`, `game.js`, `style.css` и `assets/`.
