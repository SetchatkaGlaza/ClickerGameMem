# 67: Brainrot Factory — v0.4

HTML5 idle/clicker для Яндекс Игр. Версия v0.4 делает прогрессию длиннее и добавляет активности, которые возвращают игрока в игру: сменные задания, лабораторию постоянных усилений, архив артефактов, редкие события, ежедневную награду и офлайн-доход.

## Что есть в билде

- удлинённая экономическая кривая: первый апгрейд стоит 75, престиж открывается на 25M, а финальная мутация — на 2.5B;
- комбо, критические клики, конвейер, фабрика, престиж и локальное сохранение;
- шесть стилизованных, оригинальных «мутаций» фабрики и коллекция;
- редкое событие «Сбой 67» с добровольным получением награды;
- ежедневная смена, офлайн-доход (до 4 часов), достижения, звук и мобильная вёрстка;
- три дополнительные активности: ежедневное сменное задание, лаборатория с постоянными улучшениями и коллекция артефактов;
- оригинальные SVG-ассеты: анимированный ночной фон фабрики и ядро артефакта;
- интеграционная заготовка Yandex Games SDK: `LoadingAPI`, `GameplayAPI` и rewarded video с безопасным fallback вне платформы.

## Локальный запуск

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`. Для чистого теста удалите данные сайта в браузере или нажмите «Сбросить прогресс».

## Перед загрузкой в Яндекс Игры

1. Протестировать rewarded video и сохранения в черновике Яндекс Игр.
2. Подготовить иконку, скриншоты, описание и возрастной рейтинг.
3. Проверить игру на Android/iOS и на десктопе, включая паузу при потере фокуса.
4. Собрать содержимое проекта в ZIP, где `index.html` расположен в корне архива.
