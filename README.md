# Гаражный Магнат

Браузерный idle-кликер о развитии автосервиса: от старого гаража с одним подъёмником до автоимперии.

## Запуск

Это статическая игра без сборки. Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8080
```

Затем перейдите на `http://localhost:8080`.

## Основные механики MVP

- Клик по машине: деньги, запчасти, критические ремонты и темп ремонта.
- Пять автоматизированных бизнесов с пассивным доходом.
- Пять автомобилей для коллекции с постоянными бонусами.
- Авторская мини-механика **«Идеальная сборка»**: остановите маркер в жёлтой зоне, чтобы получить +50% к бонусу автомобиля.
- Заказы, ежедневная смена, поставка запчастей, офлайн-доход, достижениях и новый филиал (prestige).
- Добровольные rewarded-видео Яндекс Игр: турбо ×3 и удвоение офлайн-награды. В обычном браузере они безопасно показывают подсказку вместо рекламы.

Сохранение хранится локально в `localStorage` под ключом `garage_tycoon_v1`.


## Арты автомобилей и гаражей

Файлы для генерации и точные пути подключения перечислены в [`assets/ASSET_GUIDE.md`](assets/ASSET_GUIDE.md). Игра сразу подхватит изображения из `assets/cars/` и `assets/garages/`; пока файлов нет, работает CSS-резервный рендер.
